# PalmoEMU

端末内のROMをブラウザで遊べるWebエミュレーターです。ゲームの実行とセーブの保存は端末内で行い、ホーム画面への追加とオフラインでの利用に対応しています。

[アプリを開く](https://sei-dis.github.io/PalmoEMU/) · [詳しい使い方・仕様](web/README.md) · [変更通知](https://sei-dis.github.io/PalmoEMU/notices.html) · [クレジット・ライセンス](https://sei-dis.github.io/PalmoEMU/licenses.html)

## 対応機種

| 機種 | 選べるコア | ROM形式 |
| --- | --- | --- |
| GB・GBC | mGBA Celio / jgenesis | `.gb` / `.gbc` |
| GBA | mGBA Celio / VBA-Next | `.gba` |
| FC | FCEUmm / jgenesis | `.nes` |
| SFC | Mesen-S / jgenesis | `.sfc` / `.smc` |
| MD | ClownMDEmu / jgenesis | `.md` / `.gen` / `.smd` / `.bin` |
| NDS（実験版） | DeSmuME 2015 / melonDS | `.nds` |

GBAの64MiB ROMと最大6MiBの拡張セーブにはmGBA Celioを使用します。VBA-NextのROM上限は32MiBです。NDSの受付上限は512MiB、それ以外は64MiBですが、端末のメモリやゲームによっては動作しない場合があります。3DSは公開版の対象外です。

mGBAのCPU速度は初期値「自動」です。通常のROMは1倍、PokemonStartの拡張カートリッジ署名を持つROMは参照元と同じ2倍を使用します。版番号には依存せず、手動設定は維持します。通信中は1倍固定です。

ROMを含むZIPからの追加にも対応します。ROM・市販機のBIOSは付属しません。各コアは検証した版を同梱しており、起動のたびに最新版へ更新する仕組みではありません。

セーブ変換は提供ツールの0.48.0版を取り込み、版ごとのデータ検査と元セーブの保護を行います。互換性のあるセーブは変換せずに引き継ぎます。詳しくは[ROM更新とセーブの引き継ぎ](web/README.md#rom更新とセーブの引き継ぎ)をご覧ください。

## はじめに

1. [PalmoEMU](https://sei-dis.github.io/PalmoEMU/)を開きます。
2. 「インポート → ファイル」から、利用する権利のあるROMを追加します。
3. ライブラリでゲームを選び、「プレイ」を押します。
4. ゲーム内でセーブし、ゲームメニューからライブラリへ戻って終了します。

iPhoneではSafariの共有メニューから「ホーム画面に追加」でWebアプリとして利用できます。初回利用時に「アプリの更新」を押す必要はありません。

「設定 → クイックスタート」をオンにすると、ゲームをタップして直接プレイできます。初期状態はオフです。「…」からはゲーム詳細や個別設定を開けます。

## 操作と表示

- タッチ、キーボード、ゲームパッドに対応。キー割り当て、連射、押しっぱなし、入力テストを設定できます。
- スキンは機種別・ゲーム別、縦画面・横画面で選択できます。標準スキンでは画面やボタンの位置・大きさ・透明度、十字キーの反応範囲も調整できます。
- `.deltaskin` / `.manicskin` を端末内から追加できます。対応する効果や操作には制限があります。[スキンの対応範囲](web/SKIN_COMPATIBILITY.md)
- 速度ボタンで1〜5倍速を切り替えます。映像フィルターも選べます。重い場合は「1倍」「ピクセル」を使用してください。
- スクリーンショットとゲーム音付きの録画に対応。カメラのアイコンから選択し、プレビューで確認して保存できます。ボタンは長押しで移動できます。[撮影の使い方・制限](web/README.md#ゲーム映像の撮影)
- NDSは下画面のタッチ、2画面の入れ替え、疑似的な「息を吹く」操作、ふたの開閉、本体言語の設定に対応します。

動作速度は端末・ブラウザ・ゲーム・コアによって変わります。対応機種のすべてのゲームで動作を保証するものではありません。確認した環境と範囲は[検証記録](web/RELEASE_VALIDATION.md)を参照してください。

## セーブとバックアップ

| 種類 | 用途 |
| --- | --- |
| ゲーム内セーブ | ゲームの「レポート」などで保存した進行。ファイルへの書き出し・読み込みに対応 |
| セーブステート | 実行中の状態を保存・再開。手動保存と自動保存があり、個別の書き出し・取り込みに対応 |
| まとめてバックアップ | ゲームを選び、設定・セーブ・ステート・保存履歴・プロフィールを保存。大きい場合は分割。ROMは含まない |

自動保存は初期状態で有効です。通常セーブと自動ステートは約2分ごとに記録し、終了時などにも保存します。mGBAではゲームの保存書き込みが落ち着いたあと、通常セーブを先に保存します。これはゲーム内のセーブ操作を自動で行う機能ではありません。

保存履歴からの復元にも対応します。セーブ・ステートはコアごとに分かれ、ステートは異なるROMやコアで使えない場合があります。大切なセーブは「セーブデータ・バックアップ」からファイルにも書き出してください。

他の端末へ移る場合は、バックアップを書き出し、移行先にも同じROMを追加してから復元します。自動のクラウド同期はありません。バックアップの対象・上限・復元手順は[保存・復旧](web/README.md#保存復旧)を参照してください。

## ROMの更新

「インポート → ROMを更新」で旧ゲームと新版ROMを選び、ゲーム内セーブを新版へ引き継げます。セーブファイル名を変更したり、書き出して再取り込みしたりする必要はありません。

- 旧ROMと旧セーブを残して、新版用の保存先へコピーします。
- セーブステートは新版へ引き継ぎません。
- 新旧ROMのセーブ互換性はゲーム作者の案内を確認してください。容量や形式の検査だけでは互換性を保証できません。

PokemonStartの旧セーブ変換にも対応します。対象条件と制限は[ROM更新とセーブの引き継ぎ](web/README.md#rom更新とセーブの引き継ぎ)を参照してください。

PokemonStartの配布情報をGitHubで確認し、新版があればライブラリとインポートに通知します。配布元の案内で作成した新版ROMを「ROMを更新」から選択してください。自動確認はオフにでき、ROM・セーブは送信しません。PKSの展開処理やROMの自動取得は含みません。

ROMファイルへのパッチ適用は「インポート → ROMパッチ」から行えます。IPS・BPS・UPSに対応し、結果は別ファイルとして保存します。既存のゲームやセーブは置き換えません。

## 通信プレイ

| 機種 | 利用できる方式 |
| --- | --- |
| GBA（Celio対応ゲーム） | 部屋番号によるオンライン通信、同じ端末で2台、対応PCブラウザでのCelio USB実機接続 |
| GB・GBC（mGBA） | 同じROMを使った端末内2台通信 |

通信は実験機能です。オンライン・端末内通信は2人用で、すべてのゲームに対応するものではありません。NDSのWi-Fi通信には対応していません。[通信の使い方・検証範囲](web/README.md#gba通信beta)

## オフラインとアプリの更新

「設定 → オフラインで使う」からアプリを保存すると、準備完了後はネット接続なしで端末内のゲームを遊べます。オンライン通信には接続が必要です。

更新が見つかり、プレイや保存・取り込みをしていなければ、「アプリの更新」を表示して反映します。プレイ中の強制更新は行いません。オフラインや取得失敗時には保存済みの版を使えます。

手動で更新する場合は、ゲームを保存・終了して「設定 → アプリの更新」を開き、その画面以外の同じアプリのタブを閉じてください。**更新のためにサイトデータを削除しないでください。**

使用中のバージョンは設定の下部に表示します。更新内容は[変更通知](https://sei-dis.github.io/PalmoEMU/notices.html)にまとめています。

## 言語とプロフィール

日本語、英語、中国語（簡体字・繁体字）、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語に対応します。「設定 → 言語」の初期値は「自動」で、ブラウザの優先言語から選びます。ゲーム自体の言語は変更しません。

設定のトレーナーカードでは、ニックネームと画像を変更し、参加日・プレイ時間・よく遊ぶゲームを確認できます。「ROMを更新」でつながった新旧版のプレイ時間は合算します。

プレイ中の画面消灯防止は初期状態で有効です。対応する端末でのみ働き、一時停止・終了・画面を離れたときに解除します。「診断と動作の計測」では、描画・音声供給・保存処理を任意で計測できます。測定値はこのタブ内に保持し、自動送信しません。

## データの扱い

ROM・セーブ・ステートは利用端末のIndexedDBに保存します。ROMやセーブをアップロードするAPIはありません。ブラウザや保存先のサイトが異なると、データは自動では共有されません。

オンライン通信を開始した場合は、Celio中継サーバーへゲームのケーブル通信データを送ります。ROM・セーブファイル全体は送りませんが、プレイヤー情報や交換内容が含まれる場合があります。

端末の故障やサイトデータの削除に備えてバックアップを保管してください。バックアップファイルは暗号化されません。[プライバシーと利用条件](https://sei-dis.github.io/PalmoEMU/privacy.html)

## 開発

Node.jsを用意し、リポジトリのルートで実行します。通常の起動に`npm install`やコアの再ビルドは不要です。

```sh
node web/scripts/serve.cjs
```

開発用URLは`http://127.0.0.1:4173/`です。このPC内からのみ接続できます。文言・変更通知を編集する場合は`npm --prefix web run dev`を使用します。翻訳モデルの初回準備は[翻訳手順](web/LOCALIZATION_REVIEW.md)を参照してください。
